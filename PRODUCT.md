# Product

## Register

product

## Users

Solo Australian operator managing a two-entity setup (GST-registered company + personal/sole trader). Single user, self-hosted. Uses primarily on desktop but reviews figures on mobile. Technical enough to self-host; not a bookkeeper — needs the tool to be fast and obvious.

## Product Purpose

A private finance manager for income tracking, expense categorisation, tax set-aside, invoicing, and EOFY deduction reporting across two entities. Success means the user can answer "how much can I actually spend?" in under five seconds and have EOFY sorted without a spreadsheet.

## Brand Personality

Precise, private, no-nonsense. The tool should feel like a terminal-native dashboard — confident and data-dense without being hostile.

## Anti-references

- Consumer fintech apps (bright blues, gamified savings goals, hand-holding copy)
- SaaS cream/sand aesthetic (warm beige backgrounds, soft rounded everything)
- Bloated enterprise dashboards (excessive whitespace, decorative charts, modal overload)

## Design Principles

1. **Data first** — numbers are the interface; chrome serves them, never competes
2. **Single-user trust** — no social proof, no onboarding theatre; the user already knows what they want
3. **Tool disappears** — consistent vocabulary screen to screen; no surprises
4. **Density without clutter** — show more when the screen allows, collapse gracefully when it doesn't
5. **Private by default** — no external fonts, no CDN calls, no telemetry signals in the UI

## Accessibility & Inclusion

WCAG AA minimum. Single user so no multi-lingual requirements. Pinch-zoom must not be blocked (remove maximum-scale=1). Reduce-motion respected for any transitions.
